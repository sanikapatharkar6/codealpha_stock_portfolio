# 📈 Stock Portfolio Tracker

A Python-based Stock Portfolio Tracker developed as part of the **CodeAlpha Python Programming Internship**.

## 📌 Project Overview

The Stock Portfolio Tracker helps users calculate the total value of their stock investments by entering stock names and quantities. The program computes individual investments and displays the total portfolio value.

This project demonstrates the use of Python dictionaries, loops, conditional statements, user input handling, and file operations.

## ✨ Features

- Add multiple stocks
- Enter quantity of shares
- Calculate investment value
- Calculate total portfolio value
- Save results to a text file
- Simple and user-friendly console interface

## 🛠️ Technologies Used

- Python 3
